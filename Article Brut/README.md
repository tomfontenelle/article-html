# 📝 Articles Bruts

Ce dossier contient vos articles en texte brut, rédigés sur Google Docs ou autre éditeur de texte.

## 📋 Utilisation

Les articles stockés ici sont les **versions texte brut** avant transformation en HTML.

## 📁 Organisation

Nommage recommandé : `[date]-[titre-court].[txt|md]`

**Exemples** :
- `2024-11-25-guide-plomberie-urgence.txt`
- `2024-11-25-optimiser-seo-artisan.md`
- `2024-11-26-choisir-electricien.txt`

## 📝 Format du Contenu

### Structure Recommandée

```
TITRE DE L'ARTICLE
==================

Introduction
------------
[Texte d'introduction...]

Section 1 : [Titre]
-------------------
[Contenu de la section...]

Section 2 : [Titre]
-------------------
[Contenu de la section...]

Conclusion
----------
[Texte de conclusion...]
```

### Éléments à Inclure

- ✅ **Titre principal** (H1)
- ✅ **Introduction** : Accroche + contexte
- ✅ **Sections structurées** : Titres clairs (H2, H3)
- ✅ **Paragraphes courts** : Faciles à lire
- ✅ **Listes** : Points clés, étapes, conseils
- ✅ **Exemples concrets** : Cas pratiques
- ✅ **Conclusion** : Résumé + CTA textuel
- ✅ **Mots-clés SEO** : Intégrés naturellement

## 💡 Conseils de Rédaction

1. **Pensez structure** : Organisez votre contenu avec des sections logiques
2. **Soyez concret** : Exemples, chiffres, cas pratiques
3. **Optimisez pour le SEO** : Mots-clés naturels, questions fréquentes
4. **Écrivez pour l'utilisateur** : Ton accessible, évitez le jargon excessif
5. **Prévoyez les enrichissements** : Notez où vous souhaitez des simulateurs, images, etc.

## 📝 Annotations Utiles

Vous pouvez ajouter des annotations dans votre texte brut pour guider la génération :

```
[IMAGE: Photo d'un plombier en action]
[SIMULATEUR: Calculateur de coût plomberie]
[CTA: Demande de devis gratuit]
[ENCADRÉ: Conseil expert]
```

Ces annotations aideront Claude IA à enrichir votre article de manière appropriée.

## 🔄 Workflow

1. **Rédiger** l'article sur Google Docs
2. **Relire et corriger**
3. **Copier** le texte (Ctrl+A, Ctrl+C)
4. **Créer** un fichier `.txt` ou `.md` ici
5. **Coller** le contenu
6. **Sauvegarder**
7. **Utiliser** ce fichier avec le prompt template
